# 질문 카드함 (hwangbum-community)

로그인 없이 누구나 질문을 올리고, 관리자가 카테고리로 정리하고, 질문마다 답변을 달 수 있는 공개 웹사이트입니다.

**GitHub + Vercel만 사용해요.** 별도 서비스(Supabase 등) 가입이 필요 없어요 — 데이터 저장은 Vercel이 제공하는 Postgres 스토리지를 그대로 씁니다.

## 구성

- `index.html` + `app.js` — 공개 페이지: 질문 작성 → "정리 전" 서랍 → 관리자가 정리한 카테고리별 서랍 → 클릭하면 답변 스레드
- `admin.html` + `admin.js` — 관리자 전용 페이지: 정리 전 질문을 카테고리에 배정 / 새 카테고리 생성
- `api/` — Vercel 서버리스 함수 (Node.js). 프레임워크 없이 파일 하나 = API 경로 하나예요.
  - `api/categories.js` — 카테고리 목록(GET) / 생성(POST, 관리자 전용)
  - `api/questions.js` — 질문 목록(GET) / 등록(POST, 누구나)
  - `api/replies.js` — 답변 목록(GET) / 등록(POST, 누구나)
  - `api/admin/verify.js` — 관리자 토큰 확인
  - `api/admin/init.js` — 테이블 생성 (최초 1회, 관리자 전용)
  - `api/admin/assign.js` — 질문에 카테고리 배정 (관리자 전용)

## 실시간 업데이트에 대해

완전한 실시간(웹소켓) 방식은 아니고, **몇 초마다 자동으로 새로고침하는 폴링 방식**이에요 (목록은 5초, 펼쳐놓은 질문의 답변은 3초 간격). 화면을 다시 켜면 바로 최신 상태로 갱신돼요. 별도 서비스 없이 GitHub+Vercel만으로 구현하기 위한 선택이라, 체감상 "몇 초 늦게 반영되는 실시간"이에요.

## 배포 & 설정 순서

### 1. GitHub / Vercel 연결 (완료됨)

이미 이 저장소가 GitHub에 올라가 있고 Vercel과 연결돼 있다면 이 단계는 건너뛰어도 돼요.

### 2. Vercel에 Postgres 스토리지 연결하기

1. [vercel.com](https://vercel.com) 대시보드에서 이 프로젝트(hwangbum-community)를 여세요.
2. 상단 탭에서 **Storage** 클릭 → **Create Database** → **Postgres** 선택.
3. 만들어진 DB를 이 프로젝트에 **Connect**(연결) 하세요.
4. 연결하면 `POSTGRES_URL`(또는 비슷한 이름의) 환경변수가 프로젝트에 자동으로 추가돼요. 따로 값을 복사해 넣을 필요 없어요.

### 3. 관리자 토큰 등록하기

1. Vercel 프로젝트 → **Settings → Environment Variables**
2. Key: `ADMIN_TOKEN`, Value: 아래 토큰(원하면 다른 값으로 바꿔도 돼요)
   ```
   8J8En6b2edKDj_j8_XPVKNrw2jtn_C5P
   ```
3. **Save**

### 4. 재배포

환경변수를 추가/변경하면 재배포해야 반영돼요. Vercel 프로젝트 → **Deployments** 탭 → 가장 최근 배포 옆 **⋯** → **Redeploy**.

### 5. 데이터베이스 초기화 (최초 1회)

1. 배포된 사이트의 `/admin.html`로 접속
2. 위 3단계의 토큰을 입력해서 로그인
3. **데이터베이스 초기화(최초 1회)** 버튼 클릭 → 테이블이 만들어져요 (버튼은 여러 번 눌러도 안전해요)

이제 공개 페이지(`/`)에서 질문을 올리고, 관리자 페이지에서 정리하고, 누구나 답변을 달 수 있어요.

## 코드 수정 → 배포까지 흐름

```bash
git add .
git commit -m "무엇을 바꿨는지"
git push
```

push하면 Vercel이 자동으로 감지해서 몇 초~1분 안에 새 버전을 배포해요.

## 나중에 자동 분류를 추가하고 싶다면

지금은 관리자가 전부 수동으로 분류하지만, `questions.category_id`로 이미 라벨이 쌓이고 있어서 나중에 이 데이터를 Claude(Anthropic API)에게 "예시"로 보여주고 새 질문을 자동 분류하게 만들 수 있어요. 그땐 `api/` 폴더 안에 분류용 서버리스 함수를 하나 추가하고, API 키를 Vercel 환경변수로 비밀 보관하면 돼요 (프론트엔드 코드에는 키가 절대 노출되지 않아요). 필요할 때 말씀해주시면 이어서 만들어드릴게요.

## 알아두면 좋은 것들

- 완전 공개 사이트라 스팸 방지 장치가 없어요. 문제가 되면 글자수 제한을 더 줄이거나 간단한 캡차를 붙이는 걸 고려하세요.
- `ADMIN_TOKEN`은 비밀번호나 마찬가지예요. 남에게 노출되지 않게 조심하고, 필요하면 Vercel 환경변수에서 언제든 새 값으로 바꿀 수 있어요 (바꾸면 재배포 필요).
- Vercel 무료 플랜의 Postgres는 사용량 한도가 있어요. 사람이 많이 몰리면 대시보드에서 사용량을 확인해보세요.
